# Installation

## Requirements

- Minecraft 26.3 and Java 25.
- NeoForge 26.3.0.115 or newer in the 26.3 line.
- CC:Tweaked 1.121.0 for Minecraft 26.3 / NeoForge. This build is currently a pre-release.
- A compatible Wi-Fi Router mod jar.

## Install

1. Install NeoForge for Minecraft 26.3 and launch the profile once.
2. Put the compatible CC:Tweaked and Wi-Fi Router jars in the instance's `mods` folder. Releases may be available from [GitHub Releases](https://github.com/Zero-Creates-Devlopment/CC-Tweaked-Wifi/releases).
3. Start the game with the NeoForge profile and check that both mods are loaded.
4. On a multiplayer server, install both mods on the server and on each client.

The router is in the existing **Functional Blocks** creative tab; it does not add a new creative tab. It can also be crafted. See [Quick Start](Quick-Start) for the recipe and setup.

Server network settings are described in [Configuration](Configuration). If the game fails to load, check the selected Minecraft and NeoForge versions, the mod versions, the Java runtime, and the launcher or server logs.
